# Inix v0.1.26

Inix is now more streamlined and user-friendly for releasing updates.

## What's new
### Version Release

You can now specify a version when running `npm run release`, making it easier to control the release process.

## Improvements
### Release Script
The release script has been improved with new options, including `--version` to specify a specific version. The script also checks for invalid versions to prevent unexpected behavior.
