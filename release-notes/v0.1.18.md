# Inix v0.1.18

**Improved Uninstall Experience**

In this update, we've made significant improvements to our uninstall process, ensuring a cleaner and safer removal of Inix from your device.

## What's new
### Installation and Uninstallation Dialogs
We've integrated electron-builder's default close/retry dialog for installation updates, making the process more convenient for users. Additionally, during uninstalls, we now force-kill the full Inix process tree before file removal, ensuring a thorough cleanup of all associated files.

## Improvements
### Installer Configuration
The installer now provides more detailed information on the uninstallation process, including the creation of Start Menu shortcuts and desktop icons (if enabled).

## Fixes
### Debug Logging
We've fixed issues with debug logging during installation and uninstallation processes to ensure accurate error reporting and debugging capabilities.
