# Inix v0.1.21

**Improved stability during releases**

## What's new
### Release rebuild now considers running Inix builds holding locks on `release/win-unpacked` to avoid failed rebuilds.

## Improvements
### Preparing a release build now includes closing any locked electron processes and creating a fresh output directory for better reliability.

## Fixes
### Fixed an issue where `release-win-unpacked` would be occasionally locked by the Defender, causing release builds to fail.
