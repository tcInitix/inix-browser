# Inix v0.1.34

A faster startup experience is now available.

## What's new
### Boot Splash UI Updates

The boot splash screen has been revamped with a new logo and animations for a more immersive experience. The updated design includes a glow effect, pulsing ring, and animated watermark.

### Performance Improvements

Internal optimizations have improved the overall performance of Inix, resulting in faster page loads and smoother browsing experiences.

## Improvements
### Theme Customization

The theme customization settings now include a new "Boot Splash" option that allows users to personalize their boot splash experience. Users can choose from various colors and animations to create a unique boot splash screen.

## Fixes
### Stability Issues

Several stability issues have been addressed in this update, ensuring that Inix is more reliable and less prone to crashes.
