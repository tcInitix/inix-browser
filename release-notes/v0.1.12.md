# Inix v0.1.12

Enhancements to improve user experience and reliability.

## What's new

*   Faster app closing: When you close the browser manually while an instance of Inix is still running in the background, it will now immediately close the remaining process.
*   Improved uninstallation: The app can automatically detect when an old version of itself has been installed on your system and prompts you to remove it.

## Improvements

*   Streamlined installer
    *   The installer now features a simpler design with clear instructions for setting up Inix.
*   Better debugging tools
    *   You'll have access to more detailed logs, making it easier to identify any issues that arise during your browsing sessions.

## Fixes

*   Resolved issues with manual closing of app instances
*   Improved uninstallation process
