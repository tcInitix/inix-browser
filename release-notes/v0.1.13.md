# Inix v0.1.13

In this version of Inix, we've added a new bookmark bar tree feature and improved various settings and download folders.

## What's new
### Download Folders
Inix now supports picking the default download folder from within the app, ensuring that downloaded files always land in the intended location.
### Bookmark Bar Tree
We've introduced support for importing, editing, and deleting individual nodes within the bookmark bar tree. This feature replaces our previous flat bookmarking system.

## Improvements

- Settings: Improved various settings shortcuts for a more streamlined experience (Settings → Privacy & Security).
- Tab Manager: Simplified tab management by removing duplicate settings paths (Tab Manager → Settings).
- Search: Enhanced search functionality with improved autocomplete and results filtering.
- User Interface: Refactored layout to ensure better accessibility and UI consistency.

## Fixes
Fixed several minor issues, including a display problem when using the new bookmark bar tree feature and an occasional crash when updating settings.

## Notes
- As always, your bookmarks have been backed up before this update. If you notice any issues with your bookmark structure, please contact our support team.
- For developers: see [electron storage/bookmark-bar.ts](https://github.com/inix-app/inix/blob/main/electron/storage/bookmark-bar.ts) for details on the new bookmark bar tree API.
