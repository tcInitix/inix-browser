# Inix v0.1.9

Enhancements to bookmark import functionality.

## What's new

- Improved support for importing Chrome bookmarks from HTML export files.
- Bookmarks now display correctly even if the original Chrome profile cannot be accessed due to file locking.

## Improvements
### Bookmark Import
- Simplified bookmarks import process with fewer steps required to get started.

## Fixes

- Various issues related to handling imported bookmarks, including improved detection of locked profiles.
- Some minor bugs were fixed in the bookmark parser to ensure correct rendering of bookmark data.
