# Inix v0.1.17

**Improved reliability and stability**

## What's new
### Force Close Feature
Inix now forcefully closes the full Inix process tree (main + GPU/utility/renderer children) when uninstalling, ensuring a complete removal of all related processes.

## Improvements
* **Installer**: The installer has been improved to better handle various user scenarios.
* **Performance**: Some minor performance tweaks have been made to improve overall browser responsiveness.

## Fixes
* **Crash Issues**: Several crash issues have been resolved to provide a more stable browsing experience.
* **Shortcut Issues**: Shortcuts for frequently used features (e.g., Settings → Tabs) now work as expected.
