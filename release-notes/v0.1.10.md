# Inix v0.1.10

Improved performance and stability for bulk bookmark imports.

## What's new
### Import Features

* New layout-based pinning system to prevent stacked bookmarks in bulk import.
* Refactored bookmark import logic with improved error handling.

## Improvements
* Minor UI tweaks across the board for better readability and flow.

## Fixes
### Known issues resolved

* Resolved issue where files locked by previous Inix installations would prevent profile import.

## Notes

Bookmarks from Chrome's bar are now added to Inix's bar. Firefox and Edge HTML exports work too.
For manual import, use Chrome's HTML export (Bookmark Manager → ⋮ → Export bookmarks).
