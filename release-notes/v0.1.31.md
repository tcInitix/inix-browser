# Inix v0.1.31
 Enhance security and stability with our latest update.

## What's new
### Relay Server Integration
We've added support for a region relay server, which protects your browsing activity while using the Inix browser.
#### Settings: Settings → Tabs → Region Relays, where you can enable this feature and configure its settings.

### Bookmark Icon Mode
You can now choose whether to use a favicon or letter icon for bookmarks in settings: Settings → Bookmarks → Edit bookmark.
#### This change improves consistency across different browsers.

## Improvements

* **Improved bookmark management**: We've made it easier to manage your bookmarks, including deleting entries and clearing history.
* **Enhanced web contents handling**: Our tab manager now better handles web contents, reducing crashes and improving overall stability.
* **Better support for proxy servers**: We've improved our support for proxy servers, making it easier to set up a custom relay server.

## Fixes

* Various fixes for minor issues, including some crashes and layout problems.
* Resolved an issue where the bookmark bar chip icon would sometimes appear as a placeholder instead of a favicon.
