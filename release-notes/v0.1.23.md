# Inix v0.1.23

### Improved Performance and Stability

Inix is now even faster at launching your private desktop experience.

## What's new
- **Improved single-instance handling**: We've made it easier for multiple instances of Inix to run simultaneously, without the risk of conflicting windows or sessions.
## Improvements
- **Optimized NSIS installer**: Our NSIS installation script has been optimized to reduce setup times and improve overall user experience.
## Fixes

We've squashed a few bugs to ensure that Inix remains reliable for all users.
