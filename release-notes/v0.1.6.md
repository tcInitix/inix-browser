# Inix v0.1.6

Improve overall build stability and performance.

## What's new
### New feature: RCEdit integration
The `afterPack` script now integrates with RCEdit to automatically apply the Inix icon and metadata to the Windows executable, making it easier to manage settings like the application name and version string.

## Improvements
* Enhance `rcedit` package to improve its compatibility with Electron 34.
* Update `vite-plugin-electron` to a newer version for better performance.
* Improve the build process by adding support for the `afterPack` script, which automates the application of settings and icons.

## Fixes
* Address issues with corrupted icon files during installation.
* Fix an error that caused some users to encounter difficulties when setting their Inix tabs.

## Notes
This update includes several behind-the-scenes improvements to enhance your overall experience. For more information on how these changes affect you, refer to the updated Inix documentation available in Settings → Help.
