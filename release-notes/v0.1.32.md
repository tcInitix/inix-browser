# Inix v0.1.32

Improvements to enhance your private browsing experience.

## What's new
### Typing Capture
We've introduced a new setting that lets you control whether typing capture is enabled in Inix. This feature allows the browser to focus on the input field when typing, making it easier to navigate and type with your keyboard. You can find this setting in Settings > Typing Capture.

## Improvements

### Vault Unlock Modal
The Vault Unlock Modal now includes a refocused auto-fill for password entry, reducing the need for manual cursor navigation.
Additionally, we've added keyboard shortcuts for quicker access to the modal: `Ctrl + Alt + U`.

### Tab Manager
The Tab Manager now focuses the shell UI (history/settings modals) on focus loss by the private window.

## Fixes

### Electron and Preload Updates
We've made stability improvements in Electron and the preload script, addressing potential crashes or performance issues.
