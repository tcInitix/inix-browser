# Inix v0.1.8

**Improved Installer Experience**

## What's new
### Improved Installer
Our installer now provides more detailed console output on the installation process, giving you better visibility during setup.

## Improvements
### Performance Boosts
Inix is running faster than ever, thanks to optimized code and reduced memory usage.

## Fixes
### Bug Fixes
- Fixed an issue where _CHECK_APP_RUNNING was not working correctly due to missing GetProcessInfo.
- Resolved a problem causing the installer to fail on certain systems.

## Notes
No new shortcuts or features were introduced in this update. Existing Settings can be accessed via Settings → Advanced → Installer.
