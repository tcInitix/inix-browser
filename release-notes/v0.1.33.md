# Inix v0.1.33

Enhanced Autofill Experience with Vault Integration.

## What's new

### Autofill Improvements
In this update, we've improved the autofill experience by integrating it with our vault feature. You can now unlock your vault to save passwords and other sensitive data, making it easier to manage your online credentials securely.

### Bookmark Clearing
We've added a new option to clear all bookmarks at once from Settings → Bookmarks. This allows you to quickly remove all bookmarks and their associated data.

## Improvements

* The settings interface has been refined for better navigation and accessibility.
* The app's overall performance and stability have been improved, providing a smoother user experience.
* New keyboard shortcuts have been added for faster navigation:
	+ Windows: `Ctrl + Shift + F` to open the bookmark manager
	+ macOS: `Cmd + Shift + F` to open the bookmark manager

## Fixes

* Various bugs have been fixed to prevent crashes and improve overall stability.
* The app's font rendering has been improved, reducing visual artifacts and improving readability.
