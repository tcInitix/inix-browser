# Inix v0.1.35

Improved performance and stability across the board.

## What's new

*   New profile avatar upload feature in Onboarding Flow
*   Quick Link settings can be saved to disk for future versions
*   Support for user-uploaded profile avatars is enabled by default (can be disabled through settings)

## Improvements

*   Improved performance and responsiveness throughout the application
*   Enhanced profile management with new features and streamlined workflow
*   Faster rendering of settings pages

## Fixes

*   Resolved issues related to duplicate profiles being created, and fixed a bug that prevented some users from accessing their profile settings
