# Inix v0.1.36

Enhance settings experience with a revamped settings sidebar.

## What's new
### New Settings Sidebar Layout
A more intuitive settings layout offers faster access to frequently used settings sections.
### Added Profiles Tab
Manage browser profiles directly within the settings app, including the option to create and edit profile templates.

## Improvements
### Autofill Profile Management
Simplified autofill profile management with a single interface for creating, editing, and deleting profiles.
### New Tab Settings
Streamlined new tab settings for faster access to key settings options.
### Private Browsing Mode
More prominent display of private browsing mode and its associated shortcut.

## Fixes
### Bug fixes for various settings sections, including the bookmarks bar and site data management.
