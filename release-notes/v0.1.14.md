# Inix v0.1.14

We've improved the app's behavior when it detects playing sound in a tab.

## What's new

### Audio Feedback for Tabs
In this update, we've added audio feedback to indicate which tabs are currently playing sound. This feature is enabled by default and can be toggled in the **Settings** menu → **Audio** section.

## Improvements

### Installer Improvements
The installer now closes windows cleanly before launching the app, ensuring a smoother experience for users. Additionally, the update process is faster and more reliable.

### Tab Manager
We've updated the tab manager to better handle audio states in tabs. This change ensures that the audible state of each tab is correctly displayed in the **TabBar**.

## Fixes

### Installer Crash Fix
A bug that caused the installer to crash on certain systems has been fixed, ensuring a stable experience for users.

Note: No new features have been added to this release.
