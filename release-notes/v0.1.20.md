# Inix v0.1.20

We've improved the release process to give you more flexibility and control over your releases.

## What's new

*   **Republish shortcut**: You can now use `--republish` as a shortcut to build and publish the current version without bumping the package version.
*   **Force notes generation**: The `--force` option will generate release notes even if there are no changes since the last tag.

## Improvements

*   Improved error handling for Git-related operations, providing more informative messages when issues arise.
*   Enhanced support for GitHub releases by automatically using archived release notes or skipping them depending on the specified settings.

## Fixes

*   Fixed an issue where the build process would hang indefinitely in certain scenarios.
