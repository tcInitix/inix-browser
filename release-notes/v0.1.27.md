# Inix v0.1.27

**Improved stability and reliability**

## What's new

### Automatic cleanup of leftover files from failed previous installs
Inix now cleans up leftover install directories when a failed uninstall occurs, reducing clutter and preventing issues.

## Improvements

* **Enhanced debugging**: Improved logging and error handling provide better insights into installation and uninstallation issues.
* **Simplified settings**: The `inixCleanupFailedInstall` function streamlines the cleanup process, making it easier to manage leftover files.

## Fixes

* **Uninstall issues**: Fixed bugs related to incomplete uninstalls, ensuring a smoother experience when removing Inix from your system.
* **Installer crashes**: Resolved issues with the installer crashing during setup, reducing the likelihood of errors.
