# Inix v0.1.7

Inix is now more transparent about its update process.

## What's new
### Update dialog improvements

The update dialog has been re-designed to be more compact and user-friendly. The release notes are now displayed in a cleaner format, making it easier for users to see what changes are included in the update.

### Installer enhancements

The installer now shows more detailed information about the installation process, including progress bars and activity logs. This should help reduce confusion during the installation process.

## Improvements
### Performance tweaks
Various performance optimizations have been made throughout the application to improve overall responsiveness and stability.
### Markdown formatting
Markdown text rendering has been improved for better readability and display consistency.

## Fixes
### Bug fixes

Several bugs have been squashed, including issues with tab management and navigation shortcuts. These should now work as expected in all cases.

## Notes
The update process is now more secure, using a PID-safe close/retry logic to prevent crashes during installation.
