# Inix v0.1.22

Improved performance when building releases with large amounts of data.

## What's new

### Performance Improvements
Inix now builds faster and more efficiently when creating release builds, which can help speed up the process for users who frequently download their app from the official website or share it via others.

## Improvements

* **Release Build Optimization**
    Inix can now build into a fresh output directory, reducing bloat in the app package and minimizing conflicts with older installers. This improvement helps maintain faster performance of the application when downloading or installing releases.
