# Inix v0.1.5

Improved performance and user experience for a better browsing experience.

## What's new

### Installation and Updates

The installer now uses PowerShell to generate the icon ICO files, ensuring a more accurate icon display on Windows.

### Quick Links

A new feature has been added to the settings page allowing users to quickly add custom links to their browser. Users can now star a webpage or import from Chrome in Settings → Library.

## Improvements

### Tab Management

The tab management system has been improved for better performance and responsiveness.

### Settings and Shortcuts

Settings are now more accessible, with shortcuts like Settings → Tabs allowing users to quickly switch between different tabs.

## Fixes

### Installer Assets

Installer assets have been updated to ensure a consistent look and feel across the platform.

### Chrome Import/Export

Fixed an issue with importing Chrome bookmarks from profiles.
